# demo_day

A polished, investor-grade interactive Next.js application designed to present and demonstrate the **SCOUT** stage of the Revenue Recovery Engine (RRE).

This presentation replaces traditional static slides with a fully interactive web experience, tailored specifically for live demo days.

## Features

- **Cinematic Design**: Dark theme, glowing accents, and smooth Framer Motion transitions.
- **Section-Based Flow**: Scroll-snapping sections explaining the exact problems with naive scraping and why SCOUT is the solution.
- **Interactive Simulation**: A live-looking SCOUT decision system simulation visualizing Strategy Selection, Waterfall Extraction, Data Cascades, and Filtering.
- **Keyboard Navigation**: Use `Space`, `ArrowUp`, and `ArrowDown` to navigate sections.
- **Presenter Mode**: Press `p` on your keyboard to toggle a discreet speaker notes panel at the bottom of the screen.

## Installation

```bash
# Move into the presentation subfolder
cd scout-presentation

# Install dependencies
npm install
```

## Running the Presentation

```bash
# Start the local development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser. Pull it up on full screen during the actual presentation.

## Customizing the Content

- **Speaker Notes**: Edit `/lib/speaker-notes.ts` to customize the copy shown in Presenter Mode.
- **Demo Presets**: Edit `/lib/presets.ts` to change the example preset URLs and the fake output data generated by the simulation.
- **Component Text**: Modify `/components/Section*.tsx` to tweak any hardcoded headlines and copy.

## Connecting to a Real Backend

By default, the demo is a **client-side simulation** to ensure 100% reliability during Demo Day without needing backend availability.

If you want to plug this into your real SCOUT API later:

1. Open `/hooks/useScoutDemo.ts`
2. In the `start()` function, replace the `buildScoutRun(url)` simulation with a fetch call:
   ```ts
   // Example
   const response = await fetch('/api/scout/run', { method: 'POST', body: JSON.stringify({ url }) });
   const scoutRunData = await response.json();
   setRun(scoutRunData);
   ```
3. Update `STAGE_DELAYS` in the same hook to match your real streaming/polling latency, or trigger stage changes via SSE/WebSocket events instead of fixed intervals.
